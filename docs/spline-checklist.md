# Checklist Spline 10 Minuti

Checklist rapida per produrre il primo MP4 marketing partendo da uno screenshot reale dell'app.

## Prima di aprire Spline

1. Scegli il frame in `app/dev/marketing-capture`
2. Usa `Fai screenshot` o `Fai screenshot singolo`
3. Recupera il PNG in `assets/marketing/screens/`
4. Apri lo storyboard corrispondente in `docs/`

## In Spline

1. Apri o duplica il template scena:
   - `hero-device`
   - `stack-devices`
2. Importa il PNG dello screen
3. Applica il PNG come texture del display del device
4. Regola camera iniziale
5. Imposta 3 o 4 keyframe massimo
6. Mantieni il testo leggibile
7. Evita movimenti rapidi o eccessivi

## Timing

1. Hook nei primi 1.5 secondi
2. Fase centrale con push-in leggero
3. Chiusura con CTA o logo

## Export

1. MP4
2. 1080x1920 per verticale
3. 30 fps
4. nome file coerente con `assets/marketing/videos/manifest.json`

## Controlli finali

1. Screen perfettamente nitido
2. Nessun crop dei contenuti chiave
3. Nessuna rotazione che distorca l'UI
4. CTA leggibile negli ultimi 1-2 secondi
5. Peso file compatibile con ads / app

## Regola pratica

Se il visual perde leggibilità, riduci subito:

- zoom
- rotazione
- numero di layer

Per AiutarSi il valore è l'interfaccia vera, non l'effetto 3D in sé.
